# La Cabaña de Don Víctor

Avance 2: sitio multipágina HTML y CSS. Abre index.html directamente o mediante Live Server. No requiere instalación. Todas las fotos usadas son locales.

## Alcance
Seis páginas: Inicio, Nosotros, Carta, Galería, Eventos y Contacto. Navegación móvil mediante details/summary nativos. Categorías de carta con enlaces a secciones. Galería enlazada a los JPG originales. Formulario demostrativo sin envío ni almacenamiento. JavaScript vacío y sin incluir; no PHP ni base de datos.
